# turbo-flask

[![tests](https://code.miguelgrinberg.com/miguelgrinberg/turbo-flask/badges/workflows/tests.yml/badge.svg)](https://code.miguelgrinberg.com/miguelgrinberg/turbo-flask/actions)

Integration of Hotwire's Turbo library with Flask, to allow you to create
applications that look and feel like single-page apps without using
JavaScript.

![Todo App Demo](examples/todos/todo-demo.gif)
